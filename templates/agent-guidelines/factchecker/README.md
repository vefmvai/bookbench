# Guidelines for book-factchecker

> The factchecker reads this file before every Phase 3 invocation.

## Index

- `trusted-sources.md` — sources to consult first.
- `outdated-sources.md` — sources to flag as stale.
- `claim-tags-rules.md` — book-specific rules for the four provenance tags.

## What goes here

- Book-specific source policy (e.g., "for topic-A, prioritise indexing platform X over open web").
- Hedging style preferences for ASSUMED claims ("by some accounts" vs "in one telling").

## What does NOT go here

- Verified-source registry → factchecker's MEMORY.md.
