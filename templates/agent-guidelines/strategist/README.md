# Guidelines for book-strategist

> The strategist reads this file at chapter planning. Lists referenced files in order.

## Index

- `structural-rules.md` — chapter structure rules for this book (e.g., "5-act structure for chapters >5000 words").
- `chapter-checklist.md` — pre-spec.md approval checklist adapted for the genre.

## What goes here

- Book-specific structural decisions ("each chapter ends with an open question").
- Restrictions on chapter templates (avoid IMRaD because the audience is not academic).

## What does NOT go here

- Quantitative parameters → `.book/config.yaml`.
- Concept registries → strategist's MEMORY.md.
