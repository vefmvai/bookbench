# Guidelines for book-writer

> The writer reads this file at the start of every chapter and the listed files in order.

## Index

- `voice-samples.md` — 3 or more reference passages by the author (200-500 words each).
- `forbidden-phrases.md` — overrides for the 46 anti-cliche patterns and per-book extras.
- `favorite-metaphors.md` — metaphor seeds the author wants to keep coming back to.

## What goes here

- Per-book voice notes ("avoid pop-cultural references from the 1990s").
- Specific term policies ("never spell out 'AI' unless first introduction").

## What does NOT go here

- Anti-cliche patterns themselves → those live in `skills/anti-ai-cliche/`.
- Used metaphors registry → writer's MEMORY.md.
