# Методология научпопа для BookBench

## 1. Identity жанра

**Научпоп — это жанр, в котором эксперт объясняет науку умному другу за чаем.** Не учебник. Не лекция. Не press-release. Договор с читателем: «у меня нет твоего образования, но у меня есть один час и интерес — расскажи так, чтобы я понял».

**Кто читатель.** Образованный взрослый без специальной подготовки в данной области. Он умеет читать длинные тексты, любопытен, не любит, когда им снисходят. Он закроет главу, если: (а) в первом абзаце не зацепили; (б) появилась формула на уровне выше «2+2»; (в) сказали «как известно» или «не будем углубляться»; (г) его 10 минут потратили на пересказ того, что он уже знает.

**Читательский договор.** Каждый абзац понятен умному читателю без специальных знаний (бабушкин тест). Каждая абстрактная мысль закрыта конкретным якорем (ladder of abstraction). Любая техника, метод, аббревиатура объяснены при первом упоминании. Читатель не должен гуглить.

## 2. Структура главы научпопа

**Каркас Pyramid (T1.1).** У главы есть один governing thought (tagline) — одно предложение, отвечающее на вопрос «что эта глава меняет в голове читателя». Под ним 3–4 саппорта (дефолт жанра); каждый саппорт раскрыт через 2–4 конкретных якоря. Параметр — `pyramid_supports_per_section: {min: 3, max: 4}`; для длинной главы можно расширить до 5.

**Каркас TED 3-act (T5.7).** Для длинных глав (≥ 20 000 знаков) полезен трёхактный формат: hook → 3 ideas → memorable close. Hook — парадокс, конкретный пример, неожиданный факт в первом абзаце; close — переходный мостик к следующей главе.

**Ladder of abstraction (T5.5).** Дефолт: 2–4 конкретных якоря на каждый абстрактный тезис. Двигайся «бытовой пример → суть → научный термин» (не наоборот). Для трудных концепций — Feynman Technique (T5.4): 1) сформулируй просто; 2) объясни как ребёнку; 3) выяви пробелы в собственном понимании; 4) упрости снова.

## 3. Поведение писателя

**Установка SFD (T3.1).** Дойди до конца главы, не вылизывая. Если зацикливаешься на абзаце — пометь TODO и иди дальше. Полировка — задача редактора.

**Voice calibration (T6.2).** Перед стартом главы прочитай 2–3 фрагмента авторского текста из `book-context/voice-samples.md`. Если их нет — попроси координатора инициировать установочное интервью.

**Author voice, не assistant (T6.3).** Ты автор, не Claude отвечающий пользователю. Не пиши «I hope this helps», «Let me know if…», «As of my last training». Не выдумывай личный опыт («я помню», «я видел», «мой опыт» — запрет). От первого лица допустимы только размышления «я думаю», «я считаю».

**Бабушкин тест (T5.2 + автор).** После каждых 5000 знаков (`writer_checkpoint_step_chars`) прогоняй контрольные вопросы:
1. Понятно ли это образованному читателю без специальной подготовки?
2. Все ли новые термины объяснены простым языком?
3. Есть ли в последних абзацах хотя бы одно эмоциональное обращение?
4. Нет ли повторяющихся структур предложений?
5. Достаточно ли конкретных примеров?

**Эмоциональные обращения.** 3–4 на главу (`emotional_addresses_per_section: {min: 3, max: 4}`). Размещение: после парадоксальных фактов или важных выводов. Формат — короткая фраза, создающая паузу для осмысления: «Вдумайтесь в эти числа», «Остановитесь и осознайте масштаб», «Подождите, не спешите дальше». Для русского научпопа допустимы и другие — voice-profile уточнит.

**Формула объяснения нового понятия (T5.4 + автор):**
1. Что это такое (простыми словами, без термина).
2. Зачем это нужно / как работает (через бытовую аналогию).
3. Конкретный пример из жизни.
4. (Опционально) Возврат к термину — «вот это и называется X».

**Микро-контекст для известных вещей.** Даже когда упоминаешь Twitter / AlphaFold / Post-it / GitHub / NumPy — давай в скобках одну фразу-микроконтекст: «Twitter (соцсеть для коротких сообщений)», «AlphaFold (программа Google для предсказания структуры белков)». Что для эксперта «известное», для читателя — нет.

**Расшифровка аббревиатур.** При первом использовании. ИИ → искусственный интеллект (ИИ); LLM → большая языковая модель (LLM, large language model). Дальше можно сокращением.

**Самодостаточность текста.** Читатель не должен гуглить. Любая упоминаемая техника / метод / подход / событие / историческая фигура объяснены: что это, как работает, пример. Исторические примеры — с минимальным контекстом (год, место, обстоятельства).

## 4. Запреты (Constitution)

**NEVER — категорически нельзя в тексте научпоп-главы:**

1. **Математические формулы и выкладки** сложнее «2+2». Замена: словесное описание сути.
2. **Программный код любого вида.** Замена: описание логики работы простыми словами.
3. **Англицизмы там, где есть русский эквивалент.** Запретные пары: «инференс → вывод/генерация ответа», «паттерн → шаблон/закономерность», «контент → материал/текст», «нарратив → изложение/повествование», «инсайт → открытие/прозрение», «фреймворк → методика/каркас», «бэкграунд → прошлое/предыстория», «бенчмарк → эталонный тест», «алайнмент → согласование», «фитбэк → обратная связь».
4. **Кальки с английского** («это делает смысл», «прийти к выводу что» вместо «решить что»).
5. **Выдуманный личный опыт** («я помню», «я видел», «мой опыт», «когда я работал в…», «мой коллега рассказывал»). Только умозрительные формулировки: «представьте инженера», «допустим, исследователь».
6. **Выдуманные факты, даты, компании, персонажи.** Если факта нет — формулировка «представьте ситуацию», «например», «допустим».
7. **Метафоры путешествия и погружения** («отправляемся в путешествие», «погружаемся в мир/глубины», «нырнём в тонкости»).
8. **Раскрытие тайн / удивительный мир** («раскрываем секреты», «удивительный мир X», «загадочный мир X»).
9. **Захватывающий / увлекательный X** без обоснования.
10. **Превосходные степени** без обоснования («самый», «лучший», «уникальный», «революционный»).
11. **Кликбейтные заголовки** («Вы не поверите», «Шокирующая правда», «То, что они скрывают»).
12. **«В этой главе вы узнаете…», «Читай главу X»** — анонсы вместо доставки ценности.
13. **Промоушн-язык** («cutting-edge», «groundbreaking», «innovative», русские: «передовой», «прорывной», «инновационный» — без конкретики).
14. **Vague attributions** («исследования показывают», «эксперты считают», «как известно», «не вызывает сомнений», «очевидно, что», «не будем углубляться»). Замена: конкретный источник или умозрительное допущение.
15. **Симметричная структура параллельных пунктов** (все 4 способа описаны идентично). Чередуй: один через историю, другой через метафору, третий через прямое объяснение.
16. **Избыточная логичность** (каждый абзац начинается «таким образом», «следовательно», «исходя из этого»). Допускай естественные отступления.
17. **Чрезмерное использование списков и -ing/-ая концовок** («формируя», «способствуя», «открывая возможности»).
18. **Эмодзи в основном тексте.** Допустимы только в маркетинговых постах (по согласованию).
19. **Длинное тире (—)** в русском тексте — если voice-profile задаёт `dash_type: medium`. Используй среднее тире (–, U+2013); дефис (-) — только внутри слов.
20. **Ассистент-обороты** («I hope this helps», «Great question!», «As of my last training data», «Let me know if you'd like…»).
21. **Sycophantic-обороты** («отличный вопрос», «прекрасное наблюдение»).
22. **Чрезмерное использование bold** (на каждое существительное). Bold — только для ключевого термина при первом упоминании или для структурного акцента.
23. **«В заключение» / «In conclusion» с generic выводом.** Концовка — конкретный факт, цифра или вопрос.
24. **Знаменует / является свидетельством / подчёркивает важность** — раздувание значимости без основания.

## 5. Стилистика и тон

**Формула голоса.** Разговор с умным другом за чаем. Не учебник, не лекция. Естественные речевые обороты, разнообразие синтаксиса, личностный подход.

**Чек-лист «человечности»** (после каждого раздела):
- Разнообразие структур предложений (короткие и длинные, простые и сложные).
- Естественные переходы (не шаблонные «таким образом / следовательно»).
- Живые примеры (конкретные ситуации из реальной жизни).
- Неожиданные сравнения (оригинальные аналогии, не банальные метафоры).
- Вариативность лексики (избежание повторов одного термина через синонимы — но и не synonym cycling: в одном абзаце один термин для одного понятия).
- Эмоциональные акценты в нужных местах.
- Ритмическое разнообразие.
- Вариативность подачи параллельных пунктов.

**Trigger → Action в стилистике:**
- Видишь в собственном тексте «как известно», «очевидно, что» → удали или замени на конкретное допущение.
- Видишь «формируя / способствуя / открывая» в концовке абзаца → переформулируй на конкретное предложение с подлежащим и сказуемым.
- Видишь два em-dash в одном абзаце → замени один из них на запятую или точку.
- Видишь bold на 3+ существительных подряд → оставь только один (термин).
- Видишь «В этой главе вы узнаете» → переформулируй через конкретный факт-приманку.

## 6. Микро-цикл главы научпопа

**Numbered Procedure из 5 шагов.** Каждый шаг — отдельный субагент в BookBench; передача артефактов через файлы.

1. **Стратег → `sections/<N>/spec.md`.** Создаёт ТЗ главы: tagline (governing thought), 3–4 саппорта, целевой читатель и его допущения, red thread keywords, plot connector с N–1 и N+1, SUCCESs-чеклист, минимум 1 пример на абстрактный тезис, выбор жанрового шаблона главы (Pyramid / TED 3-act / narrative arc). **Gate перед следующим шагом:** ТЗ имеет все 7 разделов, нет повторов с предыдущими главами (проверка через `memory: project` стратега).

2. **Писатель → `sections/<N>/draft.md`.** Пишет SFD по ТЗ; voice calibration на старте; контрольные вопросы каждые 5000 знаков; формула объяснения нового понятия для каждой концепции; 3–4 эмоциональных обращения; ladder of abstraction для каждого тезиса; самодостаточность; проверка против реестра использованных примеров и метафор. **Gate:** объём в диапазоне (мин/макс из `book-context/parameters.md`); все саппорты ТЗ покрыты; нет AI-isms из объединённого корпуса (проверка hook PostToolUse).

3. **Фактчекер → `sections/<N>/factcheck.md`.** Проверяет каждый факт / дату / цитату / отсылку. Возвращает отчёт (verified facts с URL/DOI; unverifiable claims с рекомендацией; vague attributions требуют ссылки; inconsistencies с предыдущими главами; suggested rewrites). **Gate:** нет unverifiable claims без хеджирования; нет vague attributions без источника.

4. **Редактор → `sections/<N>/edited.md`.** 4 уровня: developmental → line → copy → proofreading. Цель сокращения −10 % от draft (`editor_reduction_target_percent: 10`). Read-through соседних глав N–1 и N+1 перед line edit. Различает hard errors (правит) и taste preferences (флагирует комментом). **Audit-pass анти-ИИ-клише** — отдельный второй проход с явным вопросом: «что в этом тексте выдаёт ИИ?». **Gate:** объём (draft − 10 %); 0 AI-isms из расширенного корпуса (46 паттернов); читабельность повышена.

5. **Маркетолог → `sections/<N>/marketing.md`.** Hook-фраза (≤ 120 знаков), 3 варианта названия, аннотация по TED-структуре, социальный пост (по платформам из `book-context/parameters.md`), визуальный промпт (Midjourney / DALL-E), реестр-апдейт (использованные визуальные образы). **Gate:** все элементы соответствуют запретам жанра; визуалы новые относительно реестра.

## 7. Параметры жанра

Заполняются конкретной книгой через установочное интервью; дефолты — ниже.

| Параметр | Дефолт научпопа | Диапазон |
|----------|------------------|----------|
| `section_length.target` (знаков) | 20000 | 12000–30000 |
| `section_length.min` | 15000 | 8000–25000 |
| `transition_min_chars` | 1500 | 1000–3000 |
| `transition_min_paragraphs` | 3 | 3–7 |
| `writer_checkpoint_step_chars` | 5000 | 3000–8000 |
| `emotional_addresses_per_section` | 3–4 | 2–6 |
| `pyramid_supports_per_section` | 3–4 | 2–6 |
| `concrete_anchors_per_abstract_claim` | 2–4 | 1–6 |
| `editor_reduction_target_percent` | 10 | 5–20 |
| `audit_pass_count` | 2 | 1–3 |
| `forbid_math_formulas` | true | true / false |
| `forbid_code_blocks` | true | true / false |
| `dash_type` (русск. типографика) | medium (–) | medium / long |

**Параметры конкретной книги (через установочное интервью):**
- Voice-profile (2–3 фрагмента авторского текста как образец стиля).
- Glossary (термины и их пояснения).
- Список запретных визуальных образов (для маркетолога / Midjourney).
- Список тематических заблуждений (для фактчекера).
- Диапазон актуальности современных примеров (например, 2020–2024).

## 8. Чек-лист «человечности» главы научпопа

Финальная проверка перед сдачей `edited.md`:

- [ ] Tagline главы (governing thought) — одно предложение, отвечает «что меняет в голове читателя».
- [ ] 3–4 саппорта раскрыты, у каждого 2–4 конкретных якоря.
- [ ] Каждая абстрактная концепция закрыта бытовым примером (ladder of abstraction).
- [ ] Любая техника / аббревиатура объяснена при первом упоминании.
- [ ] Микро-контекст для известных вещей даётся даже там, где «и так понятно».
- [ ] 3–4 эмоциональных обращения распределены по главе.
- [ ] 0 запрещённых паттернов из расширенного корпуса (46): путешествие/погружение, секреты/тайны, удивительный мир, кликбейт, vague attributions, em dash overuse, bold overuse, ассистент-обороты, sycophantic, fragmented headers, generic conclusion, hyphenated word pairs, signposting, knowledge cutoff disclaimers.
- [ ] Нет матформул и кода (или их отсутствие явно обосновано).
- [ ] Нет фейк-личного опыта.
- [ ] Все факты верифицированы фактчекером (нет unverifiable claims без хеджирования).
- [ ] Plot connector с предыдущей и следующей главой (3-частный переход, 1500+ знаков).
- [ ] Объём в диапазоне `section_length.min` … `section_length.max`.
- [ ] Read-through соседних глав сделан редактором.
- [ ] Audit-pass анти-ИИ-клише пройден (двойной проход).
- [ ] Сокращение draft → edited не менее `editor_reduction_target_percent`.
- [ ] Голос соответствует voice-profile (читает как «разговор с умным другом», не как учебник).

**Если все 17 пунктов отмечены — глава готова к сдаче автору.** Если автор просит правки — вернуться на нужный шаг микро-цикла (стратег / писатель / редактор), не пересоздавая всё с нуля.
