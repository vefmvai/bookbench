# /bookbench:contribute-genre

<purpose>
Future opt-in mechanism to share a genre preset (generated by `/bookbench:research-genre`) with the BookBench community. Not implemented in 0.1.
</purpose>

<!-- ЭТАП 14: stub for 0.2+ -->

<execution>

This command is **not implemented in the 0.1 release**. It will be available in BookBench 0.2 or later.

For now, to share a genre preset with the community:

1. Locate the generated files in `${CLAUDE_PLUGIN_DATA}/user-presets/<genre>.yaml` and `${CLAUDE_PLUGIN_DATA}/user-methodologies/<genre>.md`.
2. Open a pull request at the BookBench GitHub repository (link will be added at the publish stage).
3. Place the files under `bookbench/skills/genres/<genre>/` following the structure of the existing `popular-science` preset.
4. Include evaluation cases under `bookbench/skills/genres/<genre>/tests/`.

The maintainers will review and merge.

If you want this command implemented sooner, open an issue describing your use case.

</execution>
