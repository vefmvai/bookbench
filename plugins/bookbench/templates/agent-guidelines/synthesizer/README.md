# Guidelines for book-doc-synthesizer

> The synthesizer reads this file before every /book:import synthesis pass.

## What goes here

- Author preferences for handling competing variants ("when in doubt, propose merge rather than reject").
- Custom fingerprinting parameters (e.g., longer `first-N-chars` for highly repetitive sources).

## What does NOT go here

- The propose/write modes themselves → `skills/import-synthesis-protocol/`.
- Memory schemas → those belong to each role's MEMORY.md.
