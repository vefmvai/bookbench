# Guidelines for book-strategist

> The strategist reads this file at section planning. Lists referenced files in order.

## Index

- `structural-rules.md` — section structure rules for this book (e.g., "5-act structure for sections >5000 words").
- `section-checklist.md` — pre-spec.md approval checklist adapted for the genre.

## What goes here

- Book-specific structural decisions ("each section ends with an open question").
- Restrictions on section templates (avoid IMRaD because the audience is not academic).

## What does NOT go here

- Quantitative parameters → `.book/config.yaml`.
- Concept registries → strategist's MEMORY.md.
