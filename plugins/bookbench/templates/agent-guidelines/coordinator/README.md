# Guidelines for book-coordinator

> The coordinator reads this file at the start of every task and the files it references. Keep it short.

## What goes here

- Cross-cutting rules that affect all roles' coordination — e.g., "always confirm spec gate even if config.yaml says skip".
- Author preferences for gate verbosity ("brief gates" / "full gates with diff").
- Decisions about how to handle escalations.

## What does NOT go here

- Per-role rules (those go in `agent-guidelines/<role>/`).
- Quantitative parameters (those go in `.book/config.yaml`).
- Anti-AI-cliche rules (those go in `agent-guidelines/writer/forbidden-phrases.md`).
